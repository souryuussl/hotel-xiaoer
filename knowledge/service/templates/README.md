# 酒店客服体验 · 回答模板格式

把回答模板放在本目录（`.md` 文件）。构建时，这些文件会进入「酒店客服体验」分区，不会混进「知识助手」。

## 推荐格式

```markdown
# 入住时间

> 关键词：入住, 几点, 房卡, 提前, 晚到

## 标准回答

您好，入住时间为 14:00 后。如果您提前到店，可以先寄存行李，房间准备好后我们会通知您。

## 追问

请问您大概几点到店？需要我帮您备注吗？

## 转人工

涉及当日房态或特殊安排，请转前台确认。
```

## 规则

- 文件名就是模板名，例如 `入住时间.md`。
- `> 关键词：` 一行帮助检索命中，用逗号分隔。
- 标准回答尽量控制在 50–200 字，语气像酒店客服。
- 房价、房态、天气、客流、临时停运等动态信息，写“前台核实/转前台”，不要写死数字。
- 可以增加 `## 禁答`、`## 适用场景` 等小节。
- 构建时自动跳过 `README.md` 和以 `_` 开头的文件，格式说明不会被检索。
