# 04 视频号：规则与运营攻略

> 官方依据：《微信视频号运营规范》《视频号常见违规内容概览》《微信视频号创作者权益指南》《视频号认证指南》
> 整理日期：2026-11-25 ｜ ⚠️ 动态文档，以官方最新条款为准

---

## 一、三条底层原则

1. **诚实使用** —— 虚假信息注册、故意误导、干扰真实数据等弄虚作假不被允许。
2. **分享好的内容** —— 不传播对他人有害、令人极度不适、不利于青少年身心健康的不良信息。
3. **不干扰他人** —— 直接或间接干扰其他用户使用都不被允许。

## 二、账号注册规范（运营规范 3）

- 🔴 **一个微信账号只能注册一个视频号**。违规后，微信号或绑定的身份证件、手机号码可能被禁止再次注册。
- 账号名称应与简介相符，不得与已注册账号名称重复。
- 名称/头像/简介不得含色情暴力等违法内容。
- 资料须客观、可识别、可信赖；禁止夸大、误导、过度广告性表述；不得仿冒公众人物。
- 🔴 名称不得与在先权利（商标权）、微信公众平台知名账号、其他平台知名账号重复或混淆；加无意义字母符号绕规则同样违规。
- 🔴 **禁止使用的名称类型（3.6）**：
  - 中国国家名称、国旗国徽军旗勋章、中央国家机关所在地特定地点/标志性建筑名称（外资企业名称含"中国"可用，如"宝洁中国"）。
  - 外国国家名称（外国驻华机构全称除外）。
  - 带民族歧视性。
  - 夸大宣传带欺骗性（如"国酒""中国第一酒"）。
  - 有害社会主义道德风尚或有不良影响。
  - 有歧义误导、冒充品牌、夸大宣传。
  - **日常通用名词**：正能量、吃货、星座、运势、爱情、健康、养生、百科、段子、娱乐圈、网游等。
  - 单独以地域名为名称（北京、上海、深圳）。
  - 为欺诈/违法交易沟通提供便利的命名（如用个人手机号当名称）。
- 🔴 批量注册大量相似视频号被禁止。
- 🔴 不得创建明星打投、集资、控评、八卦爆料账号；未经授权不得建粉丝团/后援会。
- 涉诈异常风险账号可被重新核验并采取限期改正、限制功能、暂停使用、关闭账号、禁止重新注册等措施。

## 四、不良信息：21 类禁止内容（运营规范 5）

5.1 国家法律法规禁止内容（11 项）。

**5.2 对网络生态造成不良影响**：夸张标题题文不符、炒作绯闻丑闻劣迹、不当评述灾难、性暗示性挑逗、血腥惊悚残忍、人群地域歧视、低俗庸俗媚俗、诱导未成年人模仿不安全行为、其他。

**5.3 侵犯他人合法权利**：知识产权（抄袭搬运）、隐私肖像、名誉荣誉（含粉丝互撕拉踩造谣）、商业秘密。

**5.4 不实信息**：政治类、煽动仇恨歧视、引起公众恐慌、邪教迷信、生活常识类、其他。

**5.5 骚扰煽动夸大误导**：标题含危害人身安全惊悚极端侮辱词汇；浮夸煽动；误导缺失掩盖歪曲时效性话题；编造夸张猎奇引战故事冲击价值观（如夸张炫富、快速赚钱经历）。

**5.6 危害平台安全**：钓鱼网站、病毒恶意代码。

**5.7 有损未成年人**：残害虐待体罚、性侵害、校园欺凌、危害人身安全、危险玩具、吸烟饮酒吸毒、披露隐私、展示婚育、厌学弃学、恶搞经典卡通、恶俗表演超身体负担、其他。

**5.8 令人极度不适**：自残自杀被杀吸毒致残枪击刺伤拷打、尸体骷髅、家暴校园暴力斗殴。

**5.9 低俗**：衣着暴露疑似裸体、性暗示、侮辱羞辱用语、非主流婚恋观、婚闹童养媳、动物交配细节、长时间聚焦隐私部位、露骨介绍情趣用品。

**5.10 卖惨扮丑**：利用未成年人残障人士骗同情、卖惨式推广、借疾病贫穷道德绑架、刻意扮丑引起不适。

**5.11 描述与实际不符**：夸张诱惑极端词汇作描述、隐藏关键信息指代不明、链接与内容无关、配音与画面不相关。

**5.12 同质化**：批量发布近似情景文案元素的同质内容。

**5.13 伪科学恐怖猎奇**：恐怖灵异、风水运势、食物相克等无科学依据内容。

**5.14 低质内容**：轮播文字大字覆盖简单拼凑；画质模糊、内容不完整、音画不相关、重复、过度剪裁、上下颠倒、黑边花屏；混剪拼接 P 图杜撰名人名言；新闻事件严重超时效。

**5.15–5.20 不规范医疗科普六类**：科学性错误；片面夸大描述；不符中医理论（祖传秘方、一招见效、根治、包治百病、神药、偏方妙招食疗治病、药食同源治癌、以形补形等）；医疗风险（正骨牵引、针灸火针放血、恶性肿瘤治疗、手术过程、急救流程不规范）；医疗营销（患者故事诱导互动、两性低俗话题、"震惊体"、片面夸大）；医疗引流（视频/评论/签名问诊、未经许可引流至个人联系方式）。

**5.21** 《视频号常见违规内容概览》所列其他违规内容。

## 五、常见违规内容概览：13 类速查

《视频号常见违规内容概览》把违规元素扩展到账号资料、视频画面、图片、封面、正文、文字、配音、配乐、评论、私信等，共 13 类：

1. **账号违规**：多次发违规动态、多次用违规资料、违规私信骚扰、多次无资质发布风险内容、大量营销灌水低俗评论、恶意留联系方式。
2. **侵权内容**：冒充身份；侵犯姓名/名称权、肖像权（恐吓偷拍公开、丑化污损 AI 伪造、未经授权使用）、名誉商誉权、隐私权；侵犯著作权（搬运抄袭洗稿；**基础编辑手段二次创作无信息增量无个人创意属侵权风险**，如加边框、裁剪画幅、镜像反转、简单转场缝合、调色、变速、插图文字、简单音频编辑）；侵犯商标权、专利权。
3. **低俗内容**：衣着暴露、性暗示、侮辱羞辱用语、违背伦理（婚外恋、婚闹童养媳）、未成年人不当行为、动物交配、聚焦隐私部位。
4. **过度营销或骚扰**：传销、无资格募捐、违规软件服务、药品医疗器械保健食品特医食品营销、搬运引流/强制广告导流、纯营销无观赏性、无资质推广风险产品、煽动性售卖、医疗养生功效营销；**虚假营销**（夸大销量好评回购、"第一/国家级/最高级"、假借权威人士机构、价格赠品与链接不符、商品服务不存在、"最后三天/仅剩 500 件"等难证实时间数量、无法验证的使用前后效果）；商品植入生硬、引导站外购买、边框角标持续露出 logo、无授权发布他人宣传片、全程只展示海报；箭头爱心手势夸张引导点击、马赛克贴纸覆盖字幕、"微信推荐/视频号推荐"话术、视频与挂链商品不相关。
5. **违法违规或令人不适**：传销赌博、暴恐血腥、管制物品违禁品、违规彩票、违规集资网贷套现、民族仇恨、邪教迷信、不实信息、不良价值观（暴饮暴食、禁片禁书、未成年人炫富霸凌、为天灾叫好、PUA）、引人不适画面（排泄物分泌物密集物、活体生食、孔洞密集画面、蛇虫鼠、厨余垃圾）、恐怖灵异猎奇（赶尸种蛊降头、跳帧惊吓、AI 特效合成残缺畸形人体）、血腥伤亡（打码不厚不全、宰杀动物、真实/仿真手术、内脏标本）。

13. **欺诈可疑不诚信**：隐瞒诱骗虚假内容致财产损失、联系方式风险不可控、**引流到视频号外平台**（明确提及其他平台账号信息、引导去其他平台搜索观看、包含其他平台链接二维码、提及其他平台同款商品）。

## 六、遵守平台要求（运营规范 6）

- **6.1** 平台自行发现或被投诉，可不经通知采取减少推荐、删除内容、暂停或终止服务；可保存信息配合监管并公告；有异议可按页面指引申诉。
- **6.2** 认证主体承担视频号权利义务，需管理管理员和运营者并为其行为负责；未认证视频号由创建时微信账号主体承担。
- **6.3** 名称、头像、简介、背景图/音乐、内容、评论如存在较高侵权可能，平台可自动限制传播。
- **6.4** 🔴 **AI/深度合成/剧情演绎必须显著标识**：利用深度学习、虚拟现实、生成式人工智能等生成合成的非真实音视频，或通过剧情演绎创作发布虚构内容，应以显著方式标识；未标识或刻意利用（如虚假摆拍）获取流量不当营销会被处罚。平台可按法规要求添加显式和隐式标识。
- **6.5** 上传发布内容不转移知识产权肖像权；但平台会在腾讯集团产品/功能/应用/智能终端及合作第三方场景中usercontent使用，并允许微信和腾讯用户分享引用编辑展示；部分场景可自行设置。含侵权素材不允许上传，平台可立即停止限制推广传播。
- **6.6** 未成年人素材须取得权利人同意；平台发现侵权可不通知删除屏蔽并处罚。
- **6.7** 直播须遵守《微信视频号直播功能使用协议》和《微信视频号直播行为规范》（见 05 册）。

## 八、认证与变现：官方门槛

### 8.1 认证（视频号认证指南）

入口：微信 → 发现 → 视频号 → 右上角人像 → 创作者中心 → 头像下方「申请认证」→ 选择类型。

- **兴趣认证**：适合无显著线下职业的爱好者（美食、旅游、摄影等）；需原创内容证明，如视频号/公众号关注数 ≥10 万或其他平台粉丝数 ≥100 万。
- **职业认证**：适合医生、律师、教师等；需 2 项证明材料（职业资格证 + 在职证明等，在职证明需含个人信息、入职时间、职位、公司信息，部分职业需盖章）。
- **音乐认证**：音乐行业资质证明或已发布高质量音乐。
- 审核 3–5 个工作日；审核中不可取消或修改。
- 🔴 个人账号只能选择一个认证词条；出镜人、申请人需与微信实名/视频号实名一致；昵称涉名人需授权。
- 认证前确认无未结算收入或余额未提现，无合作机构（需先解除）。

### 8.2 创作者权益（创作者权益指南，以实际后台为准）

| 权益 | 官方准入条件 |
|---|---|
| 短视频商品分享 | 实名认证 + 有效关注数 1000 人以上或开通微信小店 + 符合内容规范；另《商品分享视频创作指引》要求公开发表视频 ≥10 条；需在带货中心橱窗管理缴纳 100 元保证金（商家仅缴小店保证金） |
| 视频变现任务 | 有效关注数 1000 人以上 + 符合内容规范 |
| 互选平台 | 有效关注数 1000 人 + 完成实名认证 + 持续发表原创优质内容；PC 端视频号助手「创作者变现」申请 |
| 金 V 认证标识 | 万粉权益之一 |
| 媒体作者特殊通道 | 创作分成计划：有效粉丝 ≥100 + 已认证企业媒体/事业媒体；互选与短视频商品分享：有效粉丝 ≥1000 + 媒体认证；提交营业执照 + 申请函，5–7 个工作日审核 |

> 这些门槛会调整，务必以你账号「创作者中心」实时显示为准。

## 九、运营攻略（实操建议，非官方条款）

### 9.1 内容生产避坑

- 标题与封面必须和正文强相关，不用悬念断句、夸张词、惊悚封面。
- 剧情演绎/AI 特效在开头或画面显著位置标明"演绎""AI 生成"。
- 不搬运：加边框、裁剪、镜像、调色、变速、简单配乐等"基础二创"在官方文件中被明确列为侵权风险。
- 不卖惨、不要赞、不诅咒式互动；结尾 CTA 改为"你怎么看，欢迎理性讨论"。
- 系列内容要保证有下集，否则"引导关注看下集"会被判诱导。
- 医疗、财经、法律内容需资质认证；无资质不做问诊、荐股、法律建议。

### 9.2 发布前自检 12 项

- [ ] 账号名不触犯 3.6 禁用名称清单（通用词、地名、夸大词）
- [ ] 视频/封面/文字/配音/配乐均过一遍 13 类违规清单
- [ ] 无诱导点赞关注转发评论、无集赞助力
- [ ] 无站外引流（其他平台名、二维码、链接、"去某平台搜"）
- [ ] AI/演绎内容已显著标识
- [ ] 引用素材有授权，非简单二创
- [ ] 广告已显著标明，商品价格赠品与链接一致
- [ ] 无无资质医疗/金融/法律内容
- [ ] 无未成年人不当出镜、无引人不适画面
- [ ] 挂链商品与视频内容相关
- [ ] 系列内容有后续规划
- [ ] 评论区和私信也已检查（违规元素包含评论私信）

### 9.3 被限流/删除后的处理

1. 查私信通知中的不通过原因。
2. 对照《视频号常见违规内容概览》逐项整改。
3. 如认为判定有误，通过创作者中心「帮助与反馈」或设置「帮助与反馈 → 视频号」提交说明与证据。
4. 不要重复发布近似内容——同质化与多次违规会升级处罚。
