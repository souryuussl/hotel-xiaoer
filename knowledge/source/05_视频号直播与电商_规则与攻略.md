# 05 视频号直播与电商：规则与攻略

> 官方依据：《微信视频号直播行为规范》（更新 2026-07-20，首发 2021-04-29）、《微信视频号直播功能使用协议》、《微信视频号直播营销信息发布规范》、《微信小店常见问题汇总》《视频号小店开店流程指引》等

## 一、直播行为规范：适用范围与主播注册

### 1.1 适用范围

规范适用于主播、连麦的观众或主播，覆盖直播封面、标题、主播名称头像、画面背景、背景音乐、展示或叙述的内容。

### 1.2 主播注册规范（二）

1. 主播应提供真实、合法的身份信息进行实名认证。
2. 🔴 暂不接受未满 18 周岁的未成年人、未取得许可的外国人及港澳台地区居民担任主播；未取得许可或备案不得以任何方式绕过限制。
3. 🔴 被列入网络表演（直播）行业主播黑名单者不得以任何形式参与直播，违反构成严重违规。

---

## 二、信息发布规范：严重违规 = 永久封禁（三·一）

官方把直播违规分两类：**严重违规**（永久封禁）与**其他违规**（按重度/中度/轻度处罚）。

### 2.1 违法法律法规信息（1）

违反宪法基本原则；危害国家安全、泄密、颠覆政权、破坏统一；损害国家荣誉利益；煽动民族仇恨歧视、历史虚无主义、崇洋媚外；破坏宗教政策、邪教迷信；散布谣言；煽动非法集会；非法民间组织；侮辱恶搞丑化国旗国歌国徽军旗军歌；歪曲丑化亵渎否定英雄烈士；其他法律禁止内容。

### 2.2 淫秽色情赌博暴力恐怖教唆犯罪（2）

播放黄色录像露点视频、展示色情图片、发布色情资源、招嫖约炮；展示性行为、猥亵未成年人、裸露隐私部位、敏感部位特写；赌球赌马等赌博活动；展示老虎机推币机打鱼机上分器作弊器、赌博网站、红包赌博、赌博游戏、千术反千术；毒品样品/吸食注射/制作/教唆；传销组织；假币；危险刀具枪支表演；盗掘破坏文物古迹；恐怖主义极端主义；自杀他杀自残自虐、虐杀动物、血腥伤口肢解、家暴校园霸凌黑社会聚众斗殴。

### 2.3 未获许可不得发布推广（3）

枪支弹药爆炸物毒品管制刀具珍稀野生动植物烟草；募捐筹款公益慈善；宗教；新闻时政；投资融资（荐股、网贷、金融产品、证券期货有偿咨询）；VPN 翻墙软件营销/技巧；虚拟货币炒作或获取教程；需特殊资质商品服务（彩票、医疗、药品、医疗器械、农药、兽药、保健食品、特医食品）；禁播或限制的游戏动漫歌曲；宣传黑名单主播或为其引流；其他法律禁止内容。

## 三、其他违规：按情节处罚（三·二）

处罚阶梯：**弹窗提醒 → 减少推荐 → 中断直播 → 禁播 → 暂停/永久停止功能 → 封禁账号**。

### 3.1 低俗不雅 / 降低体验（1）

性挑逗动作（模拟性爱、抚摸敏感部位、抖胸抖臀、舔唇、猥琐表情、舔咬吸吮异物、反复下蹲、长时间扭胯顶胸）；低俗互动与敏感部位游戏；猜内裤颜色打屁股拔下体毛等；走光风险动作姿势；镜头聚焦胸锁骨下体臀腰大腿；俯拍仰拍凸显敏感部位；低俗语言模拟色情声音讲低俗段子；售卖展示含性暗示计生物品；低俗性暗示妆容；低俗图片视频；床上/卫生间/酒店刻意暧昧场景；脱衣舞钢管舞肚皮舞影子舞；恋足恋物恋童；尸体伤口身体残缺噱头或直播手术；特殊妆容扮丑；挖鼻挤痘挑粉刺刮舌苔掏耳朵；密集恐惧内容；聚焦昆虫蛇青蛙身体局部垃圾呕吐物病变部位动物内脏；刺耳声音；殡葬内容。

**着装红线（6–9）**：
- 不得穿国家机关/军队制服（警服军服检察院法院工商城管）；不得大面积国旗图案、不恰当场合佩戴红领巾。
- 🔴 不得穿情趣制服、单穿内衣、暴露装、透视装、肉色紧身衣、低俗图文服装、内衣外穿、三角短裤、连档上衣、裹浴巾被单、内裤套头、蕾丝眼罩等。
- 不得衣领过低露内衣露胸；衣服过薄过紧透视勾勒内衣凸点；用物品遮挡沟线；束腰绳子的勾勒胸部或胸部塞异物。
- 不得紧身衣/特定角度凸显身材曲线；背部裸露低于肩胛骨或裸露超 1/2；上衣下摆近胸部露下胸线或有走光风险；刻意露内衣营造没穿效果；男性赤裸上身或露点。
- 不得非运动场景穿瑜伽裤、过紧凸显敏感部位；下装勾勒下体轮廓；裤腰低于胯骨或露内裤；过短/不当坐姿露臀线内裤；未穿鞋刻意营造低俗；两侧开叉镂空至臀部；下体塞异物。
- 警察身份需着警服出镜，须先按《视频号政务宣传类直播准入标准》申请准入。

### 3.2 虚假博眼球危险内容（2）

伪科学（做法术改命驱鬼）；虚假宣传承诺；作弊外挂爬虫黑客盗版破解；虚假低俗恶俗噱头诱导浏览关注点赞转发送礼加热；编造事实剧本利用同情心恶意营销；套路直播（剧本演绎、假唱）；热点事件恶意营销；虚假人设头衔荣誉；封面标题留"附近 100 米""加微"；危害人身安全易模仿行为（殴打威胁、烧嘴唇、跪碎玻璃、口吞宝剑、胸口碎大石、憋气挑战、干扰驾驶、酒驾闯红灯超速、无保障高危户外）；虐待杀害小动物、血腥屠宰；生吃活物腐肉吞异物；尸体伤口身体残缺、手术；假吃催吐暴饮暴食铺张浪费。

### 3.3 未成年人（3）

🔴 禁止未成年人直播；禁止诱导胁迫未成年人点赞关注充值送礼购物或引导线下交易；未成年人出镜直播或与未成年人连麦、请未成年人当模特；利用未成年人带货诱导刷礼物；展示未成年人烟酒校园霸凌早恋教唆犯罪。

### 3.4 公序良俗负面价值观（4）

畸形婚恋观、家暴 PUA 拜金炫富性别对立；算命符文等封建迷信；破坏公物、户外骚扰恶搞路人、模仿黑社会；边驾驶边直播；浮夸进食浪费；装疯卖傻博眼球；怪诞夸张非主流奇装异服妆容；喝洗脚水电话骚扰陌生人剃头破坏财物喝酱油生吃鸡蛋活物腐肉吞异物；刻意引战挑拨关系；粗言秽语。

### 3.5 侵权与他人权益（5）

侮辱诽谤威胁恐吓恶搞攻击中伤；损害商誉商业秘密的不实信息；泄露姓名联系方式住址照片聊天记录家庭成员等隐私；煽动传播针对他人的负面信息；盗播转播他人影视剧、未经授权使用演唱他人音乐；推销仿冒三无伪劣产品。

### 3.6 低质量内容（10）

多账号直播同一内容（多机位同一视角，大型发布会演唱会晚会除外）；同质化直播；无人直播、录播、非真实开播、矩阵号直播；非真人直播（商品介绍视频、活动录像、广告片段、其他平台录像）；语音直播无互动靠录音；封面背景标题聊天主题诱导点击停留；猎奇博眼球但无实质输出或故意制造悬念；长时间黑屏挂机或定格；长时间拍天花板窗帘地板；画面模糊低清或刻意颠倒旋转；异物遮挡脸部；文字过密观感差；低质体育解说无真人出镜。

### 3.7 其他不允许（11）

诱导提供个人信息、私下交易、绕开平台管理、引流外部链接应用账号；🔴 未使用普通话直播造成理解困难；酒吧网吧夜店沐足店等场所直播；直播间抽烟或烟草不良导向（合规酒类营销科普不受此限，但需遵守专项规则如《视频号橱窗【酒类】定向准入和清退标准》）；大面积裸露纹身；鼻唇钉；诋毁损害平台形象或发布腾讯虚假恶意信息；🔴 **以教他人运营账号做副业变现为噱头并引流至直播外渠道**（自媒体/电商/直播/带货运营变现）；未经许可发布电话卡流量卡物联网卡手机号宽带资费套餐营销；法拍房推广交易引流；其他平台禁止内容。

## 六、微信小店 / 视频号小店：开店与经营

### 6.1 是什么

微信小店为商家提供商品信息展示、商品交易等产品能力，支持商家在视频号场景内开店经营。

### 6.2 开通条件与流程

- 目前仅支持**企业与个体工商户**申请资质入驻，营业执照为必需材料。
- 一个营业执照支持开 5 家店铺；一个视频号只能申请一个微信小店。
- 流程：提交商户信息 → 验证账户 → 签署开店协议 → 提交门店信息 → 开店成功。
- 入口：
  - 手机端：视频号 → 右上角个人主页 → 创作者中心 → 带货中心 → 视频号小店入口 → 开店。
  - 也可用「微信小店助手」App 或微信内搜索"微信小店开店"。
- 材料：营业执照、经营者/法定代表人身份证、结算账户（对公账户开户名须与营业执照企业主体名称一致；对私账户须与经营者一致）、超级管理员身份证/手机/邮箱。
- 账户验证：法人微信扫码 或 小额汇款验证（金额原路退回）。
- 审核一般 1–3 个工作日（帮助中心示例）。
- 类目：部分类目需定向准入与资质审核，甚至视频面试核验（如书法绘画、珠宝玉石类）。例：珠宝首饰黄金类要求外站天猫官方旗舰店/京东自营等 + 近一年流水 ≥1000 万 + DSR ≥4.7；K 金钻石铂金时尚饰品要求近一年流水 ≥500 万等。这些门槛会调整，以最新《定向准入和清退标准》为准。

### 6.3 0 保证金试运营（新规意见征集/规则）

官方规则要点：
- 申请试运营的店铺：上架销售中商品数 ≤100 个；试运营期间无法提现货款。
- 试运营结束触发条件（任一）：商家主动缴纳任意金额保证金；个体工商户有效支付订单 >100 单或支付 GMV >10,000 元；企业店有效支付订单 >200 单或支付 GMV >20,000 元；发生情节严重或特别严重违规 1 次以上、重大舆情或监管风险；平台停止该类目试运营。
- 有效支付订单剔除本地券、抽奖订单，以及自买自卖/高频刷单/物流造假/评价异常等违规订单。
- 结束试运营后需足额缴纳保证金，否则无法提交新商品上架申请且仍无法提现货款。

> 具体是否适用、金额与类目范围以微信小店后台与最新规则为准。

### 6.4 带货者（达人）路径

- 短视频商品分享权益：实名认证 + 有效关注数 1000 人以上或小店自营账号 + 符合内容规范 + 公开发表视频 ≥10 条；橱窗管理需缴 100 元保证金（商家仅缴小店保证金）。
- 路径：视频号 → 创作者中心 → 带货中心 → 去选品 / 橱窗管理。
- 发表视频或图片时在「链接或商品 → 添加商品」选择橱窗商品；**只能在发表时添加，发表后不能补加**。
- 佣金：用户点击购买、售后期结束且无退款争议后，佣金 = 商品实付金额（不含运费等）× 商家设置的达人佣金比例；打款至微信支付商户号或个人微信钱包。
- 选品建议（官方指引）：与账号内容人设契合、销量好转化高、评分高售后好；关注近 30 天销量趋势；优选联盟会清退店铺评分低的商品，已挂在视频上的商品会无法查看，影响收入。

## 七、直播与电商合规检查清单（实操建议）

### 7.1 开播前

- [ ] 主播实名认证完成，年满 18 周岁。
- [ ] 非黑名单主播；境外/港澳台身份已取得许可。
- [ ] 特殊领域（金融/健康/法律/婚恋/体育赛事/政务）已完成准入。
- [ ] 封面标题无"附近 100 米""加微"等引流语，无夸张噱头。
- [ ] 场景非酒吧网吧夜店沐足店；无烟酒精品风险。
- [ ] 着装过一遍官方 6–9 条红线。
- [ ] 无录播/无人直播/多账号同内容。

### 7.2 直播中

- [ ] 不使用普通话以外语言（如面向特定群体需评估风险）。
- [ ] 不诱导未成年人点赞送礼购物。
- [ ] 不承诺收益、不荐股、不无资质医疗建议。
- [ ] 不引导私下交易、不加联系方式、不引流站外。
- [ ] 不教"账号起号副业变现"并引流站外。
- [ ] 商品价格赠品与链接一致；广告属性显著标明。
- [ ] 不用"微信推荐/视频号推荐"等官方名义。

### 7.3 带货视频

- [ ] 视频与商品强相关，植入自然。
- [ ] 无夸大销量、绝对化用语、虚假限时限量。
- [ ] 无未授权权威人士/机构名义。
- [ ] 无明显箭头手势引导点击购物车。
- [ ] 视频与挂链商品规格质量品牌一致。
