# 00 微信生态总览与账号体系

> 整理日期：2026-11-25 ｜ ⚠️ 平台规则为动态文档，以官方最新条款为准

---

## 一、微信不是"一个 App"，而是一套彼此打通的平台

很多人把微信当成一个聊天工具，做内容或做生意时才发现：公众号、视频号、小程序、微信小店各有各的规则，但账号和数据又是互通的。先把这张关系图建立起来，后面查规则才知道该看哪一册。

```text
                      微信账号（个人实名 / 手机号）
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   微信个人号            微信支付账户            企业微信账号
   （社交关系链）         （实名 + 银行卡）        （企业认证 + 个人实名）
        │                     │                     │
        │              ┌──────┴──────┐              │
        │              │             │              │
        │          商户号        商户平台            │
        │              │             │              │
        ├── 公众号 ────┴──── 小程序 ─┴── 视频号 ────┤
        │  订阅号/服务号   独立备案/类目    账号/认证/橱窗
        │       │             │              │
        │       └── 原创/赞赏/付费 ─┐   ┌────┴────┐
        │                          │   │         │
        └───────── 微信小店 / 视频号橱窗 / 带货者 ─┘
```

**关键理解：**

- 一个能力往往横跨多个平台。比如在公众号文章里挂商品，会同时涉及公众号规则、微信小店规则和微信支付规则。
- 违规也会"跨平台传导"。公众号运营规范第 3.30 条明确：利用公众号协助违反小程序、小游戏、支付、视频号规则的行为，其他平台账号及主体会被一并处理。
- 处罚会穿透到主体。同一身份证、同一营业执照、同一实际控制关系下的账号，可能被关联封禁。

## 二、各平台定位一句话说清

| 平台 | 核心定位 | 主要用途 | 关键限制 |
|---|---|---|---|
| 微信个人号 | 人与人的连接 | 沟通、社群、朋友圈 | 不得营销骚扰、不得批量注册、不得用外挂 |
| 订阅号 | 信息传播 | 每日资讯、内容创作 | 每天 1 次群发通知 |
| 服务号 | 服务交互 | 业务办理、会员服务 | 每月 4 次群发通知 |
| 小程序 | 服务载体 | 工具类、交易类、内容类服务 | 需类目资质、需独立 ICP 备案 |
| 视频号 | 短视频与直播 | 内容分发、直播、公域获客 | 一个微信号只能注册一个视频号 |
| 微信小店 | 交易基础设施 | 商品展示与交易 | 企业/个体工商户资质，类目定向准入 |
| 微信支付 | 资金通道 | 收款、结算、退款 | 费率以商户平台核准记录为准 |
| 企业微信 | 组织协同 | 内部管理、客户联系 | 企业认证 + 个人实名 |

> 群发次数来源：腾讯客服《公众平台订阅号、服务号介绍》与《公众号/服务号的群发规则》。注意"群发通知"与"发表"是两个动作，见 02 册。

## 三、账号与主体：三套"身份"不要混

### 3.1 个人身份

- 微信个人号：手机号注册 + 实名（绑定银行卡等）。
- 视频号：一个微信账号只能注册一个视频号；违规后，微信号或绑定的身份证件、手机号可能被禁止再次注册（视频号运营规范 3.1）。
- 个人主体公众号：一个身份证可注册一个公众号或服务号；一个手机号可验证五个（公众号运营规范 1.6）。
- 企业微信：个人实名后才能添加外部联系人/微信联系人；未完成实名的境外用户不能在上下游/互联群发消息。

### 3.2 企业/组织身份

- 公众号/小程序认证：需营业执照等主体材料，部分主体需做主体真实性验证。
- 微信小店：仅支持企业和个体工商户入驻，营业执照为必需材料；一个营业执照支持开 5 家店铺（微信小店常见问题 4.1.1）。
- 企业微信认证：管理员提交企业名称、营业执照、统一社会信用代码、主体验证信息、运营者信息等。

### 3.3 平台身份（权限）

认证 ≠ 开通某项能力。比如视频号"兴趣认证"需要原创内容证明；"短视频商品分享权益"要求实名认证 + 有效关注数 1000 人以上或开通小店 + 公开发表视频 ≥ 10 条；"互选平台"要求有效关注数 1000 人。这些门槛来自《微信视频号创作者权益指南》与《商品分享视频创作指引》，会调整，使用前看后台实际状态。

## 四、规则层级：出事时按哪一条判

从高到低大致是：

1. **法律法规**：广告法、互联网广告管理办法、个人信息保护法、网络数据安全管理条例、互联网信息服务管理办法等。
2. **平台总协议**：腾讯服务协议、腾讯微信软件许可及服务协议。
3. **平台专项规范**：微信个人账号使用规范、公众平台运营规范、小程序平台运营规范、视频号运营规范、直播行为规范、外链内容管理规范。
4. **细则与公告**：类目准入标准、保证金条款、违规实施细则、规则中心公告。
5. **后台具体约定**：费率核准记录、商户平台审核结果、单次审核驳回原因。

处理具体问题时，先看 3 和 4；涉及资质和钱，再看 5。

## 五、跨平台的"通用禁止清单"

以下行为在多个平台规则中反复出现，属于第一优先级规避对象：

- 违法内容（危害国家安全、暴恐、色情、赌博、毒品、教唆犯罪等）。
- 不实信息与谣言，尤其是食品安全、健康养生、公共事件类。
- 侵权：盗用他人名义、肖像、商标、著作权；搬运、洗稿、低成本二次创作。
- 诱导分享/关注/点赞/评论/订阅，含"集赞、助力、红包 inducement、诅咒式转发话术"。
- 刷量刷粉、虚假交易、数据造假。
- 外挂、插件、脚本、多开、非官方客户端、自动化批量发布。
- 恶意对抗：多账号/多域名规避、特殊代码规避审核、寻找平台漏洞。
- 违规营销：无资质发布医疗、金融、药品、医疗器械、保健食品、彩票等内容；广告不标明"广告"。
- 隐私违规：未经同意收集手机号/身份证/位置/好友关系等。
- AI 生成内容不标识、低价值 AIGC 批量生产（见 09 册）。
