## 二、申诉与投诉路径速查表

| 场景 | 路径 | 备注 |
|---|---|---|
| 微信个人号被限制 | 客户端按提示自助解封 / 联系客服；电话 400-670-0700；腾讯客服服务号/小程序 | 🔴 永久限制登录无法解封 |
| 个人号侵权被处理 | weixin110.qq.com → 投诉维权 → 微信号侵权行为 → 侵权投诉反通知指引 | 商标/著作权/专利权 |
| 投诉个人号违规 | 对方资料页 → 右上角「...」→ 投诉 → 选类型 | — |
| 投诉群成员 | 群聊右上角「...」→ 投诉 → 选原因 → 提交聊天记录 | — |
| 公众号文章/账号被处理 | 公众号后台站内信/违规通知中的申诉入口；微信公众平台规则中心 | 按通知要求提供材料 |
| 公众号原创声明误判 | 保留底稿和创作记录，通过后台原创声明功能申诉 | — |
| 洗稿投诉 | 《微信公众平台"洗稿"投诉合议规则》流程 | 合议小组 |
| 小程序审核驳回 | 小程序管理后台查看驳回原因，修改后重新提交 | 开放社区可附 AppID 和截图反馈 |
| 小程序备案问题 | 小程序后台 → 设置 → 小程序备案 → 查看/变更/注销 | 管局审核 1–20 个工作日 |
| 外链被封 | 违规页面点「申请恢复访问」提交资料；FAQ 见 kf.qq.com | 恶意对抗可能无申诉渠道 |
| 视频号内容违规 | 违规内容页 → 投诉；或创作者中心 → 创作者服务 → 帮助与反馈 → 意见反馈 | — |
| 视频号其他申诉 | 微信 → 我 → 设置 → 帮助与反馈 → 视频号 → 意见反馈 | — |
| 视频号直播违规 | 规则中心、平台公告、私信通知查看原因，按页面指引申诉 | — |
| 微信支付商户被处罚 | 商户平台站内信/邮件通知，按指引提交材料或整改 | 争议协商不成提交财付通所在地法院 |
| 企业微信违规 | 管理员通过客户端「设置 → 帮助与客服 → 在线客服」投诉 | 需管理员核实后提交 |

## 三、定期复核清单（建议每季度一次）

- [ ] 打开本册第一节的官方链接，检查是否有更新日期变化。
- [ ] 重点看：个人号规范、公众平台运营规范、视频号运营规范、直播行为规范、外链规范、小程序运营规范。
- [ ] 检查自己业务涉及的类目规则、保证金标准、资质要求是否有更新。
- [ ] 检查后台权限门槛（视频号认证、带货、流量主等）是否与本知识库记录不同。
- [ ] 若有变化，更新对应分册顶部"依据与更新时间"，并在本册记录版本变化。
