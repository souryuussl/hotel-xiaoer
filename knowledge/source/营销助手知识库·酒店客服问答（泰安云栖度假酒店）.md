## 二、客房与入住

**Q1：酒店有哪几种房型？**
答：三类。① 山景大床房——3 楼以上推窗可见山景；② 亲子双床房——配儿童备品（儿童牙刷、拖鞋、浴袍）；③ 庭院套房——一层带独立小院，适合一家三口以上或需要安静空间的客人。
关键词：房型 / 大床 / 亲子 / 套房 / 山景

**Q2：房间多少钱一晚？**
答：房价随季节和预订渠道浮动，属于前台动态信息，我这里查不到准确数字，不敢乱报。您可以通过公众号菜单的"在线预订"入口查询当日房价，或致电前台。**（注：这正是本店菜单要补的入口——知识库只给口径，不编价格。）**
关键词：房价 / 价格 / 多少钱

**Q3：几点入住、几点退房？**
答：入住 14:00 起，退房次日 12:00 前。提前到店视房态安排，法定节假日高峰期建议先来电确认。
关键词：入住 / 退房 / 几点

**Q4：房间热水够吗？水压稳不稳？**
答：24 小时恒温热水，山景楼层水压已做过改造。这是客人留言里问过的问题（原话"房间热水够吗"），实住反馈正常。
关键词：热水 / 水压 / 洗澡

**Q5：可以加床吗？儿童怎么收费？**
答：亲子双床房自带两张床，无需加床；其他房型加床视房态确认。1.2 米以下儿童不占床免费，占床及早餐按儿童价收取。
关键词：加床 / 儿童 / 小孩

**Q6：有叫醒服务吗？想赶着看日出。**
答：有。前台登记叫醒时间即可；赶日出的客人常用 4:30—5:00 时段，天台观日出不设门槛，住客直接上顶层天台。
关键词：叫醒 / 日出 / 起床

**Q7：房间能看见泰山吗？**
答：山景大床房 3 楼以上可见山景；素材库里那张"山景房窗外"就是 3 楼山景大床房实拍——清晨五点半，日出直接进房间。
关键词：山景 / 看得见 / 景观

**Q8：有洗衣、熨烫服务吗？**
答：二楼有自助洗衣房，住客免费使用；干洗熨烫交前台，次日中午前取回。
关键词：洗衣 / 熨烫

**Q9：行李寄存？退房后还能进山吗？**
答：前台免费寄存行李，退房后仍可回酒店用茶吧、餐厅；爬山回来取行李正好。
关键词：寄存 / 行李

**Q10：入住需要押金吗？**
答：按房型收取标准押金，退房查房后原路退回。具体金额以入住时前台告知为准。
关键词：押金 / 预授权

## 三、餐饮

**Q1：早餐几点开始？多少人一份？**
答：二楼餐厅早餐自助 7:00—9:30（以当季公告时间为准），含在大部分房价内，具体以预订页面标注为准。
关键词：早餐 / 几点 / 自助

**Q2：有什么本地特色？**
答：大堂茶吧供应**泰山女儿茶**，是本地最有辨识度的特产；二楼餐厅做本地菜，山区时令菜随季节换。素材库"大堂女儿茶"图为茶吧实拍。
关键词：女儿茶 / 茶 / 特色 / 本地菜

**Q3：不住店可以来喝茶吃饭吗？**
答：可以，茶吧和餐厅对外营业；公众号粉丝出示关注页面，茶吧当季有粉丝小礼（活动以公众号推文为准）。
关键词：对外 / 散客 / 喝茶

**Q4：能订包桌、办家宴吗？**
答：二楼餐厅可承接家庭聚餐，需提前一天预订台位与菜单，细节由餐厅与客人确认。
关键词：包桌 / 家宴 / 聚餐

**Q5：孩子不吃辣，有儿童餐吗？**
答：有儿童餐具与清淡菜品，早餐区有适合孩子的粥品、点心。
关键词：儿童餐 / 不吃辣

## 四、登山与泰山

**Q1：爬泰山走哪条线？**
答：两条主流线。**红门线**：经典徒步线路，从山脚一路到山顶，全程约 4 小时，适合体力好的年轻人；**天外村线**：旅游车到中天门，再换索道上山，1 小时左右到山顶，适合带孩子或老人的家庭。**带孩子的客人建议天外村线**——这条判断来自留言区 47 次"带孩子"的真实需求。
关键词：红门 / 天外村 / 登山 / 哪条线 / 爬山

**Q2：红门离酒店多远？怎么去？**
答：约 3 公里，酒店免费接驳车可达红门登山口。
关键词：红门多远 / 接驳

**Q3：天外村离酒店多远？**
答：约 5 公里，接驳车同样可达。
关键词：天外村多远 / 接驳

**Q4：索道怎么坐？几点开？**
答：中天门索道从天外村方向换乘，运营时间随季节调整，当日运营状态以景区公告为准——**临时停运属于动态信息，知识库只给查询指引，不报具体时刻**。素材库"索道缆车"首图为中天门索道实拍。
关键词：索道 / 缆车 / 中天门 / 停运

**Q5：想看日出，几点起床？**
答：日出时刻随季节变化（夏季早、冬季晚），前台每日更新**日出时刻牌**，住客以当日牌示为准；提前一晚登记叫醒服务最稳妥。客人原话"想看日出几点起床"是留言高频问题。
关键词：日出 / 几点起床 / 日出时刻

**Q6：在酒店能看到日出吗，一定要爬山吗？**
答：不爬山也能看——酒店天台正对东面山脊，天气合适时日出直接可见；素材库"泰山日出"就是天台 05:30 实拍。想登顶看则参考红门 / 天外村两线。
关键词：天台 / 不爬山 / 看日出

**Q7：爬泰山要准备什么？**
答：常用清单：防滑鞋、外套（山顶温差大）、手电（夜爬用）、少量补给。夜爬看日出的客人多选红门线。
关键词：装备 / 夜爬 / 准备

**Q8：泰山门票多少钱？需要预约吗？**
答：票价与预约政策以景区官方当日公告为准，属动态信息，本知识库不收录数字；可指引客人查景区官方渠道。
关键词：门票 / 预约

**Q9：泰山国际登山节是什么时候？**
答：每年 9 月上旬举办，是酒店公众号"登山攻略"栏目固定的选题节点（这是选题来源③对标与节令的素材）。
关键词：登山节 / 节日 / 9月

**Q10：下雨能爬吗？孩子走不动怎么办？**
答：雨雪天登山以景区公告为准；带孩子建议天外村车 + 索道方案，山下到山上体力消耗最小。
关键词：下雨 / 孩子 / 索道方案

**Q1：可以带宠物吗？**
答：庭院套房可协商携带小型宠物，其余房型不可；以预订时确认结果为准。
关键词：宠物 / 狗 / 猫

**Q2：怎么取消或改期？**
答：按预订渠道的取消政策执行；直连预订在入住日 18:00 前可免费取消（节假日 specials 以预订页标注为准）。
关键词：取消 / 改期 / 退款

**Q3：开发票吗？**
答：支持，退房时提供抬头信息即可，电子发票 24 小时内开出。

答：婴儿床限量免费借用，预订时备注；老人入住可安排低楼层近电梯房间。
关键词：婴儿床 / 老人 / 无障碍

**Q5：接驳车怎么坐？班次？**
答：往返红门 / 天外村的免费接驳车按班次运行，班次表前台每日公示（动态信息，不收录具体时刻）。
关键词：接驳 / 班车 / 班次

**Q6：外宾 / 港澳台证件能入住吗？**
答：可，前台按规范登记有效证件。
关键词：外宾 / 证件 / 入境

## 九、营销知识点问答

**Q1：订阅号和服务号有什么区别？**
答：订阅号每天可推 1 次，折叠在"订阅号"文件夹，适合做内容；服务号每月 4 次，消息直达对话列表，有支付、预约等接口，适合做服务。酒店做内容运营一般先从订阅号起步。
关键词：订阅号 / 服务号 / 区别

**Q2：定位三要素是什么？**
答：目标用户（写给谁看）× 调性（什么口气）× 栏目规划（固定发什么）。本店建议方向：写给周末带孩子的家庭客，调性亲切实在，栏目如"登山攻略 / 日出时刻 / 房型实拍"。
关键词：定位 / 三要素

**Q3：标题怎么写？**
答：三不要——不要绝对化用语、不要空喊口号、不要装文艺。改写方向：加数字、地点、时间或动作，如"带孩子爬泰山，索道直达红门"。
关键词：标题 / 三不要 / 改写

**Q4：选题从哪来？**
答：三个来源——① 留言（客人原话就是题目）；② 后台数据（哪篇相对好就往哪加选题）；③ 对标好号（固定栏目怎么分）。每个选题注明来源和一句理由。
关键词：选题 / 写什么

**Q5：哪些词不能用（广告法）？**
答："国家级、最高级、最佳"等绝对化用语违规。本库收录常见违规词：最好、最佳、第一家、顶级、独家、史上——素材里出现一律不能发。诚信是最省钱的营销。
关键词：广告法 / 违规词 / 极限词

**Q6：自定义菜单有什么规则？**
答：一级菜单最多 3 个（每个 ≤4 字），二级最多 5 个（每个 ≤8 字）。菜单是常驻入口：图文是一次性的，菜单永远挂在对话页底部——本店菜单一直空着，是 0 单预订的直接原因之一。
关键词：菜单 / 自定义菜单 / 入口

**Q7：作品怎么算好？**
答：评价四条量规——用户针对性、调性契合、标题吸引力、排版规范；展示前先按四条自查。
关键词：量规 / 评价 / 标准

**Q8：微信营销和发传单有什么不同？**
答：微信营销是强关系营销：粉丝大多是到过店的客人，朋友圈和聊天转发是最有效的传播路径——1.8% 的打开率里，转发带来的阅读占了大头。
关键词：强关系 / 朋友圈 / 转发 / 和发传单区别

**Q9：AI 智能体能干什么、不能干什么？**
答：能自动回答重复咨询（房型、入住时间这类），替代的是重复劳动；替代不了有温度的建议和现场判断。
关键词：智能体 / 客服 / AI

答：教学素材库 8 张实拍首图 + 1 条视频，清单见附录 C。
关键词：素材 / 图片 / 首图

| 未收录事实 | 竞品酒店对比、新开餐厅、政策变动 |
| 主观承诺 | "肯定能看到日出""保证最安静" |
| 医疗 / 安全 | 高反处理、意外处置——指引前台或专业机构 |
| 投诉升级 | 只安抚 + 转前台，不在公众号里辩论 |

### 标准话术

1. **查不到**：「这个问题我核实不了：知识库没有收录相关信息。我不能编数据——您可以把看到的说法发给我核验，或记下来留给汇报环节提问。」
2. **动态信息**：「这属于当日动态信息，以前台 / 景区当日公告为准，我这边只给查询指引不给数字。」
3. **投诉**：「非常抱歉给您带来不便，这个问题我马上转前台专人跟进，稍后会有同事联系您。」
4. **疑似违规词**：「这个说法涉及绝对化用语（违反广告法），建议改为具体事实描述，比如加上数字、地点、时间。」
